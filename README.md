# Monsterjagt

Et monster-fanger-spil til hele familien — lavet til iPad, på dansk.

- [CLAUDE.md](CLAUDE.md) — arkitektur, hvordan man kører projektet, og hvordan man tilføjer indhold.
- [HOW_TO_ADD_A_MONSTER.md](HOW_TO_ADD_A_MONSTER.md) — sådan laver du dit eget monster (til børnene).

## Kom i gang

```
npm install
npm run dev -- --host
```
